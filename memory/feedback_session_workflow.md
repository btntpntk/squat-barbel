Always follow this order when implementing a new feature set:

1. **Explore first** — read all relevant files before writing anything
2. **Ask clarifying questions** — the user answers concisely; don't skip this step even if the task seems clear
3. **Write CLAUDE.md** — before any code, document the architecture and integration points
4. **Present a development plan** — phased, with files, decisions, and gotchas; user confirms before coding starts
5. **Implement phase by phase** — mark todos as completed in real time
6. **End session with README.md + memory update** — always write these at the end

**Why:** The user explicitly requested plan-before-code and documentation-at-end in this session. Skipping either step will feel incomplete.

**How to apply:** At the start of a new implementation task, propose this sequence before starting. At the end of a session, offer to write/update README.md and memory files.
